# Gypsie Locs Hair Studio

Custom marketing site for Gypsie Locs Hair Studio (Waterford, MI). Booking is handled by [GlossGenius](https://gypsielocshairstudio.glossgenius.com/) — every **Book Now** button opens that flow in a new tab.

## Local preview (XAMPP)

1. Project path: `C:\xampp\htdocs\gypsie-locs-hair-studio`
2. Open: `http://localhost/gypsie-locs-hair-studio/`
3. PHP 8+ recommended

## Pages

| Path | Purpose |
|------|---------|
| `/` | Brand hero + CTAs |
| `/services/` | Service menu (seeded from Ultra listing) |
| `/portfolio/` | Filterable gallery (placeholders until photos) |
| `/about/` | Joanna + suite |
| `/contact/` | Address, phone, maps |
| `/book/` | Handoff page → GlossGenius |

## Config

Edit `includes/config.php` for phone, address, domain, Instagram, and GlossGenius URLs.
